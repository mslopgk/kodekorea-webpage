# 코드코리아 홈페이지 — 디자인 시안 설계

- **작성일**: 2026-07-28
- **승인**: 사용자 승인 완료
- **목표**: B2B 수주·신뢰 확보
- **산출물**: Next.js 프로젝트 1개 + 컨셉 테마 4벌
- **언어**: 한글 우선 + 영문 병기

## 배경

TeamHub 체크리스트 "코드코리아 홈페이지 제작 — 디자인 시안 평가 → 디자인 결정 및 최종완성 → 서버 배포"의 첫 단계. 4벌을 비교 평가해 1벌을 고르고, 나머지를 제거하면 그대로 실물 사이트가 되는 구조여야 한다.

레퍼런스 분석은 `docs/references.md` (#01 Hut 8, #02 Sentra, #03 HLE, #04 Robin Thomas) 참고.

## 구조

Next.js 15 App Router + Tailwind CSS 4.

```
/                 시안 비교 인덱스 (4벌 링크 + 컨셉 요약)
/c/hut8           컨셉 A
/c/sentra         컨셉 B
/c/hle            컨셉 C
/c/robin          컨셉 D
```

- **콘텐츠 단일 소스**: `content/site.ts`. 4벌이 전부 여기서 읽는다. 같은 회사·같은 문구를 디자인만 바꿔 비교하는 것이 목적이므로 컨셉별 문구 하드코딩을 금지한다.
- **공용 토큰**: `lib/tokens.ts` + `app/globals.css`. 간격·타이포 스케일·모션 이징은 공유하고, **팔레트만 컨셉별로 오버라이드**한다.
- **디렉토리 소유권**: 각 컨셉은 `app/c/<slug>/` 아래에서만 파일을 만든다. 공용 파일은 수정하지 않는다. (병렬 작업 충돌 방지)

## 콘텐츠 모델

3개 사업축으로 회사를 설명한다.

1. **AI 솔루션** — BubbleMap(제조 도면 AI). 근거: 도면 36개·67페이지 전량 분석, 치수/주석 13,022건 추출, OCR 실패 0건, 테스트 56/56 통과, YOLO26 + OCR + VLM 교차검증 파이프라인.
2. **AI 교육** — 두봇/BlockPy(Blockly↔Python 무손실 양방향 IDE, CPython ast 단일 IR), CV 강의 시즌1 16화, 교재 제작, LMS.
3. **플랫폼 구축** — TeamHub(협업툴 + MCP 서버), 부산대·부산시 공공디자인·장영실AI연구원 웹/앱.

**운영 역량**을 신뢰 근거로 추가: 자체 VPS + Cloudflare 전환으로 외부 호스팅비 월 $39 → $0, self-host Supabase 스택, 메일 78계정 이관(mailcow).

### 익명화 규칙
클라이언트명·내부 수치는 `content/site.ts`의 `ANONYMIZE` 플래그로 제어한다.
- `true`(기본): "국내 대형 제조사" 식으로 치환. 수치는 유지.
- `false`: 실명 노출.

공개 배포 시 실명 사용은 **해당 클라이언트 동의 후**에만 `false`로 바꾼다.

## 컨셉 4벌

각 컨셉은 완결된 홈페이지 1벌이다. 히어로 → 사업축 3개 → 실적/수치 → 운영 역량 → CTA/푸터를 모두 포함한다.

### A. `/c/hut8` — 기업 신뢰형
- 무채색 베이스 + 액센트 1개. **섹션 단위 명암 대반전**(다크 히어로 → 라이트 3D 씬 → 다크 푸터).
- 아이소메트릭 3D 지형을 카메라가 이동하며 3개 사업축을 통과. 축 사이를 액센트 색 라인이 연결.
- 자간은 em 기반 3단계(-0.04 / -0.03 / -0.02em), 헤딩 line-height 1.
- 8컬럼 / max 1600px / 24px 거터.
- 실적은 지형 위 핀 + 라벨로 시각화.

### B. `/c/sentra` — 엔지니어링 임팩트형
- 흑백 + 오렌지 1개. 오렌지는 CTA 아이콘 박스에만.
- **글자 스크램블 디코드**를 등장 모션으로 통일. 단 영문·숫자에만 적용(한글은 마스크 와이프).
- 이미지는 1비트 디더링 필터로 통일.
- 코드형 인덱스 라벨(`S/01`, `A/02`).
- 벤토 그리드는 세로 선에서 좌우로 펼쳐지며 컬럼별 스태거 등장.
- 다크 → 라이트 섹션 반전 시 네비/버튼 자동 반전.

### C. `/c/hle` — 서사형
- 3D 오브젝트(서버랙 또는 모니터) 안으로 카메라 진입 → 화면이 뷰포트가 되어 본문 시작.
- **핵심**: 진입 전 화면에 내부 섹션을 축소 렌더해 "지금 방송 중인 화면 속으로 들어간다"는 논리를 성립시킨다. (HLE의 핵심 발상)
- 기술 도면풍 그리드 배경 + 액센트 사각형이 그리드를 따라 이동.
- 로딩을 콘텐츠로: 프리로더에서 카피의 마지막 단어만 바꿔가며 반복 타이핑.
- 다만 프리로더 최대 대기 3초 상한을 둔다(HLE의 20초는 이탈 유발).

### D. `/c/robin` — 실험형
- START 게이트 + 스크롤 여정. 막마다 팔레트를 갈아엎어 "이동했다"는 감각을 만든다.
- 화이트아웃을 씬 전환 장치로 사용.
- 정보를 오브젝트에 붙인다(기술 스택을 궤도 라벨로).
- **스크롤 속도 게이트는 제거한다.** 트랙패드·저감도 입력·접근성 도구 사용자를 가두는 구조이며 기업 사이트에 부적합. 일반 스크롤 진행으로 대체.

## 타이포그래피

- 한글: **Pretendard Variable** (오픈 라이선스). 본문·헤드라인.
- 영문·숫자·라벨: **JetBrains Mono** 또는 **IBM Plex Mono** (오픈 라이선스).
- 유료 폰트(ITC Franklin Gothic Std, PP Supply)는 **사용 금지**. 레퍼런스에서 스펙만 참고.
- 한글 헤드라인에 음수 자간을 크게 주면 자소가 붙어 읽기 어렵다. 한글은 -0.01~-0.02em, 영문은 -0.03~-0.04em으로 분리 적용.

## 공통 제약

- 모든 모션·3D는 `prefers-reduced-motion: reduce` 시 정지 상태로 폴백.
- 모바일(<768px)은 3D를 정지 이미지/CSS로 폴백. WebGL 컨텍스트 생성 실패 시에도 콘텐츠가 보여야 한다.
- 네이티브 스크롤 유지. `html/body { overflow: hidden }` + 커스텀 스크롤 컨테이너 구조 금지 (#03·#04에서 접근성 문제 확인).
- 스크롤 진행률을 속도·연속 입력에 의존시키지 않는다.
- 이미지는 SVG/CSS/캔버스 우선. 래스터가 필요하면 placeholder로 두고 경로만 명시.

## 검증 기준

각 컨셉이 다음을 만족해야 완료:
1. `npm run build` 통과.
2. 데스크톱(1920) / 태블릿(768) / 모바일(390)에서 레이아웃 깨짐 없음.
3. `prefers-reduced-motion` 켠 상태에서 모든 콘텐츠 도달 가능.
4. 콘텐츠는 전부 `content/site.ts`에서 읽음 (문구 하드코딩 0건).
5. 유료 폰트 참조 0건.
