# 메일 기반 실적 원장

출처: `ubuntu@mail.kodekorea.kr` (156.228.4.147, mailcow-dockerized) · 추출일 2026-08-03

## 어떻게 뽑았나

```bash
ssh -i ~/.ssh/id_ed25519_new ubuntu@mail.kodekorea.kr
sudo docker exec mailcowdockerized-dovecot-mailcow-1 \
  doveadm fetch -u <계정> 'mailbox date.sent hdr.from hdr.to hdr.cc hdr.subject' ALL
```

- 메일박스 **117개** 중 메일이 있는 **115계정**, 총 **6,305통**의 헤더를 덤프
- RFC2047 인코딩·접힘 헤더를 파이썬 `email.header`로 디코드해 TSV로 정규화
- rspamd가 `[FAKE]` / `[SPAM]`으로 태깅한 발송자 위조 스팸이 수백 통 섞여 있어 전부 제외
- 결정적인 13건은 `doveadm fetch ... text`로 원문(.eml)을 받아 첨부파일명까지 확인

### 읽지 않은 것

`busan01–22` · `sajik1–20` · `swdau.ai01–10` · `etedu1–5` · `donghae1–2` ·
`kodekorea1000번대/2000번대` 계정은 **교육 프로그램 참가자에게 발급한 계정**이다.
회사 자산이지만 내용은 제3자의 사적 통신이므로 **본문을 읽지 않았다.**
프로그램명·기수·시기 같은 실적 정보는 계정 명명 규칙과 대표 계정 메일에서 확인했다.

## 8. 사이트 반영 시 지켜야 할 것

1. **`ANONYMIZE = true`를 임의로 끄지 않는다.** 회신본 §0-3 기준 실명 노출 동의를 받은
   클라이언트가 아직 없다. 실명은 `content/site.ts`에 `client(실명, 마스킹)` 형태로만 넣었다.
   공공기관 실적은 관행상 공개 가능성이 높지만 **판단은 대표가 한다.**
2. 금액은 메일에서 확인된 것(3,139,000원 ×2)만 쓴다. 견적 2안은 제안이므로 제외.
3. `제안` 등급은 사이트의 실적 영역에 넣지 않는다. 역량 영역에만 반영한다.
